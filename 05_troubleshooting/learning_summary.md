Learning Summary

This assignment helped me become more comfortable using command-line tools for everyday development tasks.

I practised navigating directories, creating and managing files, checking system information, working with environment variables and running Python programs.

The Python and Qiskit examples helped connect terminal work with actual programming. I also learned how shell scripts can automate repetitive tasks and how to approach common errors by checking paths, permissions and dependencies.

Overall, I now have a better understanding of how terminals, development tools and automation fit together in a software workflow.
